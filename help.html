⚡ Introduction / Pengenalan

Revit Automation Suite is a high-performance, enterprise-grade Autodesk Revit add-in designed to automate tedious quality control audits, bulk data exports, parametric 3D structural rebar modeling, and standards management across all infrastructure and building projects.

Built with dual-runtime engines supporting Autodesk Revit 2021 through 2027+, it offers instant 0.13-second audits, ClosedXML 5-sheet formatted Excel workbooks, interactive HTML dashboards, and one-click JSON standards portability.

Revit Automation Suite adalah platform add-in Autodesk Revit kelas enterprise yang dirancang untuk mengotomasi audit kualitas model BIM, ekspor massal jadwal dan gambar, pemodelan tulangan 3D parametrik, serta standarisasi geometri di seluruh divisi proyek infrastruktur maupun gedung.

Mendukung Autodesk Revit 2021 hingga 2027+ (.NET Framework 4.8 & .NET 8.0), add-in ini memberikan kecepatan audit 0.13 detik, laporan Excel 5-Sheet ClosedXML berformat rapi, dashboard HTML interaktif, dan ekspor/impor standar JSON sekali klik.

🔍 BIM Model Quality & Dimension Checker

The Model Checker executes rigorous dual-phase quality audits on the active Revit model or an entire folder of .rvt project files in batch mode.

📋 How to Use:

Step 1: Select Active Project Preset

Choose your project standard profile (e.g. PT Hutama Karya (Persero) V1.8, PUPR Building, or Custom Profile).

Step 2: Choose Audit Scope

Select Current Active Model for instant single-file audit, or Batch Models to scan a folder of project files.

Step 3: Run Audit & Inspect KPIs

Click ▶️ Run Quality Audit. In less than 0.2 seconds, compliance cards, score gauges, and element violation lists will populate.

Step 4: Generate Reports

Click 📊 Export Excel Report (5-Sheet) for official submission workbooks or 🌐 View HTML Report for interactive executive summaries.

Model Checker menjalankan audit kualitas dua fase pada model Revit yang aktif atau seluruh folder file .rvt dalam mode batch.

📋 Cara Penggunaan:

Langkah 1: Pilih Preset Standar Proyek

Pilih profil standar acuan (misal PT Hutama Karya V1.8, PUPR Bangunan Gedung, atau Custom Profile).

Langkah 2: Tentukan Cakupan Audit

Pilih Model Aktif Saat Ini atau Batch Models untuk memeriksa banyak file dalam satu folder.

Langkah 3: Jalankan Audit

Klik ▶️ Jalankan Audit Kualitas. Dalam 0.13 detik, skor kelulusan dan daftar pelanggaran parameter langsung tampil.

Langkah 4: Buat Laporan Resmi

Klik 📊 Ekspor Laporan Excel (5-Sheet) untuk buku kerja ClosedXML resmi atau 🌐 Buka Laporan HTML.

⚙️ Box & Structure Standards Editor

Accessible via the ⚙️ Edit Standards button in the Model Checker dialog. Allows non-programmers to define geometric dimensions, tolerances, and family types directly inside Revit.

Key Features:

  • Dimension Tolerances: Configure margins for Dimensions (±mm), Slope (±%), and Skew Angle (±°).
  • Family & Type Management: Add new types (➕ Add Type) or delete outdated types (🗑️ Delete Type).
  • Inline Table Editing: Double-click any parameter value in the table to modify its benchmark target.
  • 📤 Export JSON: Saves the standards to a standalone file to share across your team.
  • 📥 Import JSON: Loads an external team standard file into your local Revit with 1 click.

Diakses melalui tombol ⚙️ Edit Standar di jendela Model Checker. Memungkinkan pengguna mengatur dimensi standar, toleransi, dan tipe family tanpa menyentuh kodingan.

Fitur Utama:

  • Toleransi Margin: Mengatur batas toleransi Dimensi (±mm), Kemiringan Slope (±%), dan Sudut Skew (±°).
  • Manajemen Tipe: Menambah tipe baru (➕ Tambah Tipe) atau menghapus tipe lama (🗑️ Hapus Tipe).
  • Edit Nilai Langsung di Tabel: Klik nilai pada tabel untuk mengubah angka target standar.
  • 📤 Ekspor JSON: Menyimpan file standar untuk dibagikan ke rekan tim lain.
  • 📥 Impor JSON: Memuat file standar tim ke komputer Anda dalam 1 detik.

📊 Batch Schedule Exporter to Excel

Replaces Revit's cumbersome single-file .txt export by packaging multiple ViewSchedules directly into beautifully formatted Excel workbooks (.xlsx).

  • Preserves header styling, row alignments, and numeric formats.
  • Auto-generates clean grid borders and auto-fitted column widths.
  • Exports to either multi-sheet tabs in a single workbook or individual clean workbooks.

Menggantikan proses manual ekspor file .txt Revit dengan menggabungkan puluhan tabel ViewSchedule langsung ke dalam 1 file Excel (.xlsx) rapi.

  • Mempertahankan format header berwarna, rata tengah/kanan, dan format ribuan angka.
  • Garis border tabel otomatis rapi dan lebar kolom otomatis menyesuaikan panjang teks.
  • Bisa digabung multi-sheet dalam 1 file Excel atau dipisah per file.

📐 Batch Sheet to DWG Exporter

Batch exports Revit drawing sheets and plans into AutoCAD DWG files with guaranteed AutoCAD 2018 format compatibility.

Ensures contractors and external consultants using older AutoCAD versions can immediately open and review your drawings without version conflicts.

Mengekspor massal lembar gambar (*sheets*) Revit ke format AutoCAD DWG dengan jaminan kompatibilitas AutoCAD 2018.

Memastikan konsultan dan kontraktor yang menggunakan versi AutoCAD lama tetap bisa membuka file gambar tanpa hambatan.

🧱 3D Box Culvert Rebar Modeler

Generates parametric 3D structural reinforcement rebar inside Box Culvert nested families in under 3 seconds.

  • Calculates outer stirrups, inner distribution bars, and longitudinal ties.
  • Automatically models Head Wall and Foot Wall rebar cages.
  • Enforces precise concrete cover clearance offsets.

Memodelkan tulangan 3D parametrik lengkap pada nested family Box Culvert dalam waktu kurang dari 3 detik.

  • Menghitung sengkang luar, tulangan bagi dalam, dan tulangan memanjang.
  • Otomatis memodelkan tulangan sayap Head Wall dan Foot Wall.
  • Menerapkan selimut beton presisi sesuai spesifikasi teknis.

Area pengaturan aturan terproteksi (PIN: 110921) bagi Lead Engineer & BIM Manager untuk mengatur regex nama file, kata kunci kategori STR/ARS/MEP, matriks LOIN, serta sinkronisasi dari script Dynamo (.dyn).
